# Podcasts de IA

Buscador web de podcasts de inteligencia artificial. Un solo archivo (`index.html`), sin dependencias ni build.

## Probarlo en local
Abre `index.html` con doble clic en tu navegador.

## Publicarlo con GitHub Pages
1. Sube el proyecto a un repositorio de GitHub.
2. En el repositorio: **Settings → Pages**.
3. En *Build and deployment* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Guarda. En uno o dos minutos estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Añadir podcasts
Edita el array `DATA` dentro de `index.html`.
